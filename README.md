# hairstyle.company

Static site (GitHub Pages) for hairstyle.company, a curated edit of human hair wigs and hair care from UNice, Zlike, Allove Hair and Jumy Bee.

The HTML pages are **generated**. Edit the source files below, then rebuild:

```bash
node scripts/build.mjs
```

| What | Where |
|---|---|
| Brands, The Edit (12 curated), store products, affiliate links | `data/partners.json` |
| Site name, email, newsletter form URL, social links | `src/site.json` |
| Guides, FAQs, collections, About/Disclosure/Privacy | `src/content.mjs` |
| Theme and scripts | `src/site.css`, `src/site.js` |

Official stores: https://www.unice.com · https://zlikehair.com · https://www.allovehair.com · https://jumybee.com
